# Restricciones del sistema

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema debe desarrollarse como una aplicación accesible mediante un navegador web. |
| RC02 | Control de versiones | Los documentos y archivos del proyecto deben gestionarse con Git y mantenerse en un repositorio de GitHub. |
| RC03 | API REST | La comunicación entre la aplicación web y los servicios del sistema debe realizarse mediante una API REST. |
| RC04 | Pasarela de pago | El sistema debe integrarse con una pasarela de pago externa para procesar las operaciones de pago. |
| RC05 | Servicio de envío | El sistema debe integrarse con un servicio externo de envío para gestionar las entregas de los pedidos. |
| RC06 | ERP | El sistema debe integrarse con el ERP para consultar información de productos y stock. |
| RC07 | Servicio de facturación | Si se utiliza un servicio externo de facturación, el sistema debe enviarle los datos necesarios para generar comprobantes de pago. |
