# Atributos de calidad

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | Las consultas de productos y las operaciones del carrito deben responder rápidamente, incluso cuando haya muchos usuarios conectados al mismo tiempo. |
| AC02 | Disponibilidad | El sistema debe permanecer disponible durante las campañas comerciales y permitir que los usuarios realicen sus operaciones. |
| AC03 | Escalabilidad | El sistema debe soportar un aumento de usuarios y solicitudes sin afectar significativamente su funcionamiento. |
| AC04 | Seguridad | Los datos de usuarios, cuentas y compras deben estar protegidos contra accesos no autorizados. |
| AC05 | Mantenibilidad | El sistema debe estar organizado para permitir cambios y correcciones sin afectar innecesariamente otras funcionalidades. |
